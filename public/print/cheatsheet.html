1動かす　早見表

資料: chirimen.org/pizero

つなぐ

  1. microSD カードを差し、パソコンと USB ケーブルでつなぐ (起動まで約 2 分)
  2. ターミナルを開く
    chirimen.org/PiZeroWebSerialConsole/PiZeroWebSerialConsole.html
  3. [Connect and Login PiZero] > [接続]
  4. [wifi panel] に SSID とパスフレーズを入れて [SET WiFi] > [wifi Info] で確認

書く

[myApp] > [移動] > [Create New Text]
ファイル名を入れて書く > [Save]

動かす・止める

node hello.js
止めるには Ctrl + C

LED を点滅させる (hello.js)

import { requestGPIOAccess } from "node-web-gpio";
const sleep = (ms) => new Promise((resolve) => setTimeout(resolve, ms));

const gpioAccess = await requestGPIOAccess();
const port = gpioAccess.ports.get(26); // 26 番ポート

await port.export("out"); // 出力モード

while (true) {
  await port.write(1); // 点灯
  await sleep(1000);   // 1000 ms 待つ ← この数字を変えてみよう
  await port.write(0); // 消灯
  await sleep(1000);
}

見本を取る

[CHIRIMEN Panel] > [Get Examples] > ID を探す > 回路図のとおりに配線 > [JS GET] > node main-○○.js

困ったとき

  • 画面が固まった: USB ケーブルを抜く > もう一度つなぐ > ターミナルを再読み込み > [Connect and Login PiZero]
  • LED が光らない: LED の向き (足の長いほうが GPIO 側)、差したピンの番号を見直す
  • センサーが動かない: [i2c detect] に番号が出るか見る。出なければ配線を見直す
  • エラーが出た: ファイル名のまちがい、[Save] のし忘れを見直す
  • 配線を変えるとき: USB ケーブルを抜いてから
